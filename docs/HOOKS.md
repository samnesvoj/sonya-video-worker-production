# Режим «Хуки» (hooks-teaser-v1, 2026-11-16)

Владелец: «нужно, чтобы ИИ находил самые супер накопленные моменты в видео — драки, сцены на грани — а потом идёт
обычный вирал-режим. Просто режим вирал + добавить именно хук».

**Что получается:** те же клипы, что в «Вирусных» (тот же отбор, тот же Gemini-редактор, кроп fill_9x16, субтитры,
минимум клипов как в virality), но каждый клип начинается с хука 1,5–3 с → белая вспышка 0,12 с + тихий «вжух» → клип.

## Откуда берётся хук (решение)

1. **По умолчанию — из самого клипа** (тизер его пика), не из первых 4 с клипа (хук не повторяет начало дословно).
   Почему: хук гарантированно про то же самое; зритель видит развязку в этом же клипе (досматривание); клип не
   обещает того, чего в нём нет — «обманные» хуки платформы режут и на них жалуются.
2. **Из другого места видео** — только если Gemini видит, что момент про тех же людей/ту же историю и заметно
   сильнее всего в клипе (например, спокойный разговор перед дракой). Никогда не из другого выбранного клипа
   (отступ 3 с), один такой момент — максимум на один клип.

## Как ищутся острые моменты (без NSFW-моделей, ничего не генерируется)

| сигнал | что ловит |
|---|---|
| громкость z + скачок относительно 4 с до | крик, удар, взрыв, хлопок |
| высота голоса z (озвученные секунды) | визг, крик |
| разница кадров 4 fps 64×36 в клипе, без склеек | резкое движение (драка, погоня) |
| склейки в окне | быстрый экшен-монтаж |
| лица YuNet из кроп-анализа (кэш, второй прогон не нужен) | два лица рядом (поцелуй/лицом к лицу), крупный план, губы |
| YOLO-поза на кадре кандидата (yolo11n-pose) | двое вплотную + рука вытянута к другому / вверх (драка), двое слились (объятия) |
| слова GigaAM | смех, мат, «что?!», «да ладно», конфликт/романтика/шок, «!» |
| Gemini (один вызов на видео) | тексты кандидатов + теги + коллажи кадров с подписями → id хука + safety |

Безопасность: `ok` / `edgy` (на грани: поцелуй, флирт, драка без крови, мат — можно) / `unsafe` (откровенный секс,
нагота, кровь крупно… — никогда). Плюс короткий список откровенных слов → кандидат не используется. Флаг —
`teaser.safety` в `selected_segments.json`.

## Бюджет

Gemini-хуки делят лимит владельца 1,5 ₽/видео с редактором клипов. Картинка ≈ 1060–1110 токенов при любом размере
(замер на Timeweb), поэтому кадры идут коллажами 4×5 (20 кадров = цена одного). Если не влезает — сначала
убираются коллажи, потом кандидаты из других мест. Без редактора — локальный лучший кандидат.

## Рендер

Хук режется тем же кропом 9:16 и с теми же субтитрами, его хвост получает вспышку + «вжух» (короткое
перекодирование 2–3 с), затем хук + клип склеиваются копированием потоков (перекодирование только если параметры
кодирования не совпали). `.ass` клипа сдвигается на длину хука (баннер SONYA и сайт читают время реплик из него).
Ошибка хука никогда не роняет клип: клип уходит без хука, `teaser_status` объясняет почему.

## Включение / выключение

- Сайт: карточка «Hooks» (`clipType=hooks` → mode `virality`), воркер: `cut_profile` ставит `params.teaser`.
  `hook=1` в параметрах virality даёт то же самое.
- Выключить без отката релиза: `SONYA_HOOKS_TEASER=off` в fleet.env → хуки-задания выходят как обычная virality.

# Runbook
**Release:** PR → `ci` green (tests, manifest==lock, gitleaks, pip-audit, docker build) → bump `version` in `release/manifest.json` → merge → protected tag `worker-vX.Y.Z` → `git rev-parse worker-vX.Y.Z^{commit}` = new SHA → GPU smoke with that SHA → set `SONYA_RELEASE_SHA` in the Template/dispatcher. Dependency change: regenerate lock (`uv pip compile requirements/worker.in --python-version 3.11 --python-platform x86_64-manylinux_2_28 --generate-hashes --index-strategy unsafe-best-match -o requirements/worker.lock.txt`), `python tools/update_release_manifest.py`, run `publish-base-image`, update image digest. Model change: `tools/make_models_lock.py`.
**Rollback:** set the previous `SONYA_RELEASE_SHA` (and digest). Commits are immutable. Bad running instances: stop assigning, destroy (SIGTERM requeues the active job).
**Recovery:** lost instance → server stale-requeue (heartbeat every 120 s) → new instance from the Template, no manual setup. Restart on the same disk: verified release is cached, no token needed. GitHub down at start → fail-closed, no jobs.
**Migration from the old Vast build** (`sonya-worker:fast`, ghcr private; archived in `provenance/archive-docker`, do not delete the old image): create a separate Template, one instance with `ENABLED_MODES=virality`, a test job in an agreed window; shift traffic via the dispatcher (VPS change, yours); rollback = point the dispatcher back to the old image/Template (<5 min). Differences: old image bakes code into layers, writes secrets to `.env.local`, defaults to `MODE=trailer_film_breaker`, unpinned deps, root, no health/readiness.

Нагрузка (минуты GPU на видео, размер моделей, время старта) — **допущения**: GPU-прогонов ещё не было.

## Источники
- Цены/поля предложений: Vast API `POST /bundles/` через `vastai search offers` (поля `dph_base`, `storage_cost` $/ГБ/мес, `internet_*_cost_per_tb`), выборка: 1 GPU, CUDA≥12.4, reliability>0.98, verified, диск≥80 ГБ, inet_down>200 Мбит/с.
- Правила биллинга: https://docs.vast.ai/documentation/reference/billing , https://docs.vast.ai/documentation/instances/storage , https://docs.vast.ai/documentation/instances/managing-instances
- Курс: https://www.cbr.ru/scripts/XML_daily.asp

## Что говорит документация Vast (проверено 2026-11-07)
- **GPU тарифицируется только пока инстанс активен** (per second). Остановленный инстанс «отсоединён от GPU» — GPU-часы не идут. «Loading» (скачивание образа) **не тарифицируется**.
- **Диск тарифицируется каждую секунду существования инстанса, в том числе остановленного** («Stopping an instance does not avoid storage costs»). Ставка диска у остановленных «может быть выше», точный коэффициент в документации не указан — в модели ×1 (риск занижения; в `usage.EstimateParams.stopped_storage_multiplier` настраивается).
- **Трафик тарифицируется по использованию, в любом состоянии**, отдельно от $/час.
- **Возобновление не гарантировано**: статус `Scheduling`, GPU может быть занят другим арендатором («stuck >30 s — likely rented»), ожидание может быть бесконечным; рекомендация Vast — создать новый инстанс. Истёкший контракт нельзя перезапустить.
- Нулевой баланс: инстансы останавливаются, диск продолжает списываться; без карты данные уничтожаются.

| RTX 4090 | $0.53 / 43.81 ₽ | $0.06 / 4.78 ₽ | $0.01 / 0.88 ₽ | ≈ 11 |

Диск 80 ГБ — главная статья расходов при редком использовании: сутки хранения стоят примерно как 2–3 часа работы GPU. Размер диска влияет линейно (диск 40 ГБ вдвое дешевле); минимальный безопасный размер определится после GPU-теста (образ torch+CUDA, модели, временные видео).

**Рекомендация для SONYA с небольшим числом пользователей (до ~10–20 видео в сутки).** Останавливать инстанс через 60 с простоя (требование), но **не держать остановленный диск долго**: `SONYA_STOPPED_RETENTION_SECONDS=1800` — 30 минут нужны, чтобы повторные загрузки сразу после первой шли через быстрый RESUME; затем DESTROY. Стоимость хранения 30 минут ≈ $0.01 / 0.91 ₽, холодный CREATE ≈ $0.04 / 2.92 ₽. STOP+RESUME на целые сутки оправдан только при очень частых пробуждениях (таблица выше). RESUME не гарантирован (GPU может быть занят), поэтому в коде есть fallback на CREATE и уничтожение зависшего диска. Режим 24/7 для такой нагрузки дороже в разы (≈3–15× в зависимости от числа видео, см. таблицы).

# Трейлер (production, 2026-11-17)

Карточка «Трейлер» на сайте (`clipType: trailer`) → воркер, режим virality → `modes/virality/runner.py::_trailer` →
`scripts/shared/trailer/pipeline.py`. Пока владелец не одобрит, задания может создавать **только админ**
(API), остальные видят «Временно недоступен».

## Формат (память trailer-tiktok-reference, trailer-tone-verdict)
TikTok-пересказ ОДНОЙ сюжетной линии от первого лица героя: хук из середины → предыстория → нарастание → поворот →
клиффхэнгер. Тон энергичный и дерзкий, мат точечно, людей по именам не называть, факты только из расшифровки, шутки —
явные (gag). Картинка фильма 3:4 крупно на 9:16 поверх своего размытого фона, субтитры в стиле сайта НА картинке
(не за кадром), заголовок-крючок первые ~3 с, белая вспышка после хука, маленькая концовка SONYA (1,3 с).

## Шаги
1. `script.py` — Gemini (Timeweb flash-lite, только анализ и текст, ≤ `SONYA_TRAILER_BUDGET_RUB`=1,5 ₽):
   A) выбор линии по расшифровке GigaAM; B) текст рассказчика с коллажами кадров эпизода (Gemini выбирает кадры K…
   под каждую фразу); один текстовый ремонт при дефектах (имена, длина, первое лицо, порядок); C) фактчек против
   фраз расшифровки. Таймкоды — только по словам GigaAM.
2. `shots.py` — один проход ffmpeg по эпизоду (5 к/с): лица (YuNet), движение, склейки → кадры и коллажи.
3. Рассказ: **`narration.py` (по умолчанию)** — голоса нет, рассказ идёт субтитрами (2,7 слова/с, паузы на точках),
   звук — оригинальный звук фильма. `voice.py` — место под голос (`SONYA_TRAILER_VOICE=qwen`), включать только после
   выбора голоса владельцем. Интерфейс один и тот же: `{n: {sec, wav, words}}`.
4. `edit.py` — каждая фраза → кадры, которые её показывают (выбор Gemini > момент, который фраза пересказывает >
   рядом > вся линия), ритм склеек 1,3–2,8 с (быстрее к концу), склейки на паузах между словами, без повторов.
5. `render.py` — кроп по главному объекту (лица), лёгкий наезд на статичных кадрах, звук −14 LUFS, проверки: длина,
   звук, ширина каждой строки субтитров ≤ безопасной зоны (иначе шрифт уменьшается), контактный лист.
6. Выход: `trailer_main.mp4` (~60–100 с) + до 2 коротких `trailer_short_N.mp4` (24–52 с) + `trailer.json`.

## Выключатели
- `SONYA_TRAILER=off` (fleet.env) — воркер отказывает в заданиях трейлера понятной ошибкой `TRAILER_DISABLED`.
- `SONYA_TRAILER_VOICE=off|qwen` — голос (по умолчанию off).
- `SONYA_TRAILER_BUDGET_RUB` — лимит Gemini на видео (1,5).
